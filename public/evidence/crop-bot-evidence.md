# Crop Bot - Regional Yield Screening Evidence

## Contribution
Samuel Faulkner built and checked a hackathon presentation application for four-region corn-hybrid screening. The work joined data reconciliation, interactive decision support and supplied-model inference replay.

## Recorded work
The application exposes parent-pair and location predictions, regional thresholds, review flags and downloadable candidate rows. It uses supplied model checkpoints and a two-seed ensemble, rather than training a new model inside the app.

## Recorded outcomes
Using the supplied row-level region labels corrected a regional count mismatch. The curated record reports inference replay differences below 0.001 bushels per acre across all four regions. That agreement measures reproduction of supplied predictions, not accuracy against future yields.

## Evaluation discipline
The workflow keeps RMSE, normalized RMSE, R-squared, rank correlation, threshold accuracy, precision, recall and baseline behavior separate. Retrospective evaluation and weak regional performance remain visible rather than being converted into a misleading accuracy headline.
